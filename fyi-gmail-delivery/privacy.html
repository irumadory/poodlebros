FYI Gmail Delivery 개인정보처리방침

FYI Gmail Delivery는 운영자 본인의 시황 보고서 전달과 전송 확인에만 Google 사용자 데이터를 사용합니다.

접근하는 데이터와 목적

승인한 Gmail 계정의 주소, FYI 메일의 수신자·제목·거래일·메시지 식별자·발송 상태·본문을 사용합니다. 발송 권한은 확정된 HTML 보고서를 승인된 수신자 한 곳으로 전송하는 데 사용합니다. 읽기 권한은 보낸편지함의 FYI 발송 기록을 찾고 특정 메시지의 본문을 원문과 대조하는 데 사용합니다. Google의 gmail.readonly 권한은 전체 메일에 접근할 수 있는 범위이며, 보낸편지함에만 한정된 권한은 아닙니다.

사용 제한

메일 삭제·수정 권한을 요청하지 않습니다. Google 사용자 데이터와 인증정보를 광고, 판매, 이용자 프로파일링 또는 AI 모델 학습에 사용하지 않습니다. Gmail에서 읽은 메일을 시황 생성 모델의 입력으로 전달하지 않습니다. 시황 분석에는 별도로 수집한 공개 시장자료를 사용합니다.

보관과 처리 서비스

계정 연결을 완료하면 연결을 유지하기 위한 인증정보는 운영자가 승인한 AWS 서버의 접근이 제한된 전용 저장소에 보관합니다. Google OAuth 및 Gmail API와 AWS 호스팅을 필요한 처리에 사용합니다. 인증정보와 접근 토큰을 보고서·일반 실행 로그·검토 ZIP에 포함하지 않습니다. 발송 확인에 필요한 식별자와 원문 해시 등 최소 기록은 중복 방지와 오류 복구를 위해 보관합니다.

연결 해제와 삭제

사용자는 Google 계정의 타사 연결 관리에서 접근을 철회할 수 있습니다. 권한 철회가 서버의 인증파일·기존 보고서·발송 검증 기록·백업을 자동 삭제하지는 않습니다. 자료와 백업은 운영자가 별도로 정리할 때까지 보관될 수 있습니다. 삭제 요청은 사용자 지원 연락처로 접수하고 운영자가 수동 처리합니다.

Google 정책

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

안내 페이지 제공

이 안내 페이지를 GitHub Pages에서 제공할 경우 GitHub는 서비스 보안 등을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. GitHub 개인정보처리방침을 참고할 수 있습니다. 이 페이지에는 광고·분석 스크립트가 없습니다.
